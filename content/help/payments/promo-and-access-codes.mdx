There are two kinds of code. A **promo code** takes money off paid tickets: an early-bird discount, a group deal, or free places for volunteers. An **access code** unlocks tickets that are otherwise hidden, such as speaker or sponsor tickets. Buyers type either one on the registration form.

<Callout kind="permission">

Owners, admins, and co-organisers with the **Edit details** permission on the event or series.

</Callout>

## Creating a promo code

The **Promo codes** card appears on the event's **Settings** tab (or the series page) once the event has at least one paid ticket.

<Steps>

1. In the **Promo codes** card, choose **Add code**.
2. Enter the **Code**: 3 to 32 letters, numbers, dashes or underscores. Codes aren't case-sensitive.
3. Choose **Percent off** or **Amount off**, then whether it applies to **Each ticket** or **The whole order, once**.
4. Enter the **Percent** (1 to 100) or the **Amount**.
5. Set any of the optional limits described below.
6. Choose **Add code**, and write the code down.

</Steps>

<Callout kind="warning">

Codes are stored scrambled. After you add one, the app only ever shows its first three letters, so note the full code before you leave the page. Nobody can look it up later.

</Callout>

### Limits you can set

| Field | What it does |
| --- | --- |
| **Ticket** | **Any paid ticket**, or just one of them. |
| **Fewest tickets in the order** | The code only works when the order has at least this many eligible tickets. Use it for group discounts, for example 5. |
| **Discounted tickets per order** | For **Each ticket** codes: how many tickets in one order get the discount. Blank: every eligible ticket. |
| **Orders that can use it** | How many orders may use the code in all. Blank: no limit. |
| **Works from** and **Works until** | When the code can be used, in your device's time zone. |

### How discounts are worked out

- **Each ticket** takes the percentage or amount off every eligible ticket, up to the per-order limit.
- **The whole order, once** takes the discount off the eligible tickets together, once per order.
- A discount never takes a ticket below zero, and a 100% code makes the tickets free.
- Promo codes discount tickets only. Extras and booking fees are always charged in full.
- Only one promo code can be used per order.

## Tracking and stopping codes

Each code in the list shows its first letters, the discount, and how many times it's been used, out of its limit if it has one. An order counts as using a code while it's confirmed, while its buyer is paying, or while it's waiting for approval or a waitlist place. If a payment runs out or a request is declined, the use is freed up again.

To stop a code, choose **Stop code** and confirm. It can't be used again, and orders that already used it keep their price. Codes can't be edited: to change one, stop it and add a new one. Each code can only be added once per event or series.

## Hiding tickets behind an access code

<Steps>

1. Add or edit a ticket in the **Tickets** card.
2. Under **Who can buy it**, choose **Only with an access code**.
3. Enter the **Access code**: 3 to 32 letters, numbers, - or _.
4. Save the ticket, and share the code with the people it's for.

</Steps>

Like promo codes, access codes are stored securely and you won't see them again. The ticket list shows an **Access code** chip with the code's first letters. When editing the ticket, leave the code blank to keep it, or type a new one to replace it.

Give several tickets the same access code to unlock them together, for example a speaker ticket and a speaker-plus-guest ticket.

## What buyers see

On the registration form, a buyer with an access code types it into **Access code** and chooses **Unlock**. The hidden tickets appear alongside the public ones, marked "Unlocked with your code". A promo code goes in the **Promo code** field, and the discount shows in the total before they pay.

If a code doesn't work, the buyer sees why, for example that it isn't valid right now, has been used up, doesn't apply to the tickets they chose, or needs more tickets in the order.

## Good to know

- An access code only reveals tickets; it doesn't discount them. To give the same people a lower price, set the hidden ticket's price lower, or create a promo code for it too.
- For tickets shown only to your organisation's members, choose **Only organisation members** instead. See [Ticket types, group tickets and add-ons](/help/payments/ticket-types#hidden-and-members-only-tickets).
- A series' codes work across all its dates and passes.
- Free places for helpers? A 100% promo code limited to one ticket and a few orders works well, or add the guest yourself as complimentary: see [Orders and receipts](/help/payments/orders-and-receipts).
